# Список задач

Веб-приложение для управления списком задач.

## Возможности

- добавление новых задач;
- отметка задач как выполненных;
- удаление задач;
- фильтрация задач;
- отображение количества активных задач;
- сохранение задач в localStorage.

## Технологии

- HTML5
- CSS3
- JavaScript
- DOM API
- ES Modules
- localStorage

## Запуск

Для запуска проекта необходимо открыть `index.html` через локальный веб-сервер.

Например, проект можно запустить с помощью расширения Live Server в Visual Studio Code.

## Структура проекта

```text
todo-app/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    ├── main.js
    ├── ui.js
    └── storage.js
```
